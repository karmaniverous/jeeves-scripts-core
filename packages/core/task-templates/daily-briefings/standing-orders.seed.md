# Standing orders

Append-only. Every entry is dated and attributed: `- YYYY-MM-DD (<who>): <order>`. Never edit or delete an entry; a later entry can supersede an earlier one.

## Report structure

- YYYY-MM-DD (<who>): Two separate reports: market intel is shareable, the action-item briefing is internal only.
- YYYY-MM-DD (<who>): BLUF first, then detail.

## Content focus

- YYYY-MM-DD (<who>): Follow-ups from meetings, calls and email.
- YYYY-MM-DD (<who>): Carry items forward until explicitly complete.

## Handling rules for recurring noise

- YYYY-MM-DD (<who>): <Topic> is handled through another channel on a fixed schedule: mention it briefly, never flag it as overdue.

## Cleared Items

Permanent suppressions. Each entry means: this topic or person is resolved or must never appear again. Don't carry it forward, don't create new items about it, don't mention it.

- YYYY-MM-DD (<who>): <Topic or person>.
