## Rules shared by the morning briefing and the end-of-day list

**Carry forward across both artifacts.** Read the latest morning briefing and the latest end-of-day list:

1. The more recent of the two is the baseline.
2. Items in the older one that are missing from the newer one carry forward too, so nothing drops when a run was skipped.
3. Open items carry forward until someone marks them complete.

**Reconcile checkboxes.** {{principal}} ticks boxes in the rendered document:

- An open item that is checked moves to ✅.
- A ✅ item that is unchecked moves back to the open section that matches its owner: {{principal}} is saying it isn't done.
- Checkbox state beats chat feedback when they conflict.
- When both artifacts hold the same item, the more recent checkbox state wins.

**Feedback becomes standing orders.** Feedback in {{deliveryChannel}} that states a lasting preference is appended to this report's `standing-orders.md` (named above), dated and attributed; never edit an existing entry. One-off remarks only shape this run. An item or person under **Cleared Items** never appears again: don't carry it forward, don't create new items about it, don't mention it.

**Dates.** Use the date line at the top of this task, in {{timeZone}}. Never infer today's date.
