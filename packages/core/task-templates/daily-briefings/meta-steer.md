This directory holds a daily report series, its append-only `standing-orders.md` and its TASK file (if the instance has its own). Besides synthesising long-run priorities and recurring themes, audit conformance: say whether the recent reports honour each standing order, whether any topic or person under **Cleared Items** has resurfaced, and how report size is trending (lines and bytes over the last two weeks, with the largest sections). Recommend new standing orders where the same feedback or pruning recurs, as proposals for the principal to confirm, never as instructions.
